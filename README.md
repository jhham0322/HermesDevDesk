# Hermes DevDesk 0.8.11

0.8.9: 긴 대화의 화면을 40개 메시지 단위로 유지하고 이전/다음 기록과 최신 메시지로 이동할 수 있습니다. 메시지 추가 시 기존 화면을 재사용하며, 본문 문단을 하나의 텍스트 컨트롤로 묶고 접힌 도구 결과는 펼칠 때 렌더링합니다. 스트리밍 이력 저장은 2초 간격으로 묶고 완료·종료 시 저장합니다.

연결 설정에서 **새 모델 / 저장 / 선택 모델 삭제**로 모델을 관리합니다. 각 모델은 **모델명, 모델 URL, 토큰**을 독립 저장합니다. 기본은 Chat Completions부터 확인하며 Claude Messages와 Responses도 지원합니다. 전체 API URL을 입력하면 해당 방식을 사용합니다. 인증은 Bearer 토큰입니다. URL은 base URL, `/v1`, 완전한 `/v1/messages` 모두 지원합니다. 고급 설정에서 다른 지원 프로토콜이나 `x-api-key` 인증을 지정할 수 있습니다. 전송 시 선택 모델의 URL·토큰을 적용하고 연결이 바뀌면 엔진을 다시 연결합니다. 실행 중인 요청은 중단 후 모델을 바꿉니다.

**JSON 내보내기 / JSON 가져오기**는 모델별 연결을 옮깁니다. 가져오기는 같은 모델명을 갱신하고 다른 모델은 추가합니다. JSON에는 토큰 원문이 포함됩니다. 앱 내부 저장은 Windows 사용자 DPAPI 보호를 유지합니다. 세 필드만 있는 JSON도 가져올 수 있습니다:

```json
[
  {
    "ModelName": "your-model-name",
    "ModelUrl": "https://your-company.example/v1/messages",
    "Token": "your-token-value"
  }
]
```

로컬 검증은 합성 토큰과 로컬 서버만 사용했습니다. 공식 엔진으로 동일 채팅에서 A → B → A의 서버·모델·인증 전환을 확인했습니다. 5,001개 메시지의 WPF 검사에서 화면 컨트롤은 40개, 추가 렌더링은 약 7ms였습니다(이 PC의 측정값).

0.8.11은 Chat API의 답변 조각을 즉시 전달합니다. 이전 구현은 Chat 요청을 비스트리밍으로 보내고 응답 전체를 기다리다가 4분 제한으로 실패할 수 있었습니다. 서버의 일시적인 지연이나 대기열도 시간 초과 원인이 될 수 있으므로 외부 장애로 단정하지 않습니다. 실행 요청은 `messages`의 텍스트를 문자열로 전달하고 `max_tokens`를 사용하며 불필요한 `parallel_tool_calls`를 보내지 않습니다. 실제 에이전트·도구 호출·후속 답변까지 스트리밍으로 검증합니다.

설치 경로는 항상 `%LOCALAPPDATA%\Programs\HermesDevDesk\App`입니다. 새 설치본을 임시 폴더에서 검증한 뒤 기존 App 폴더를 전체 교체하므로 이전 앱 파일과 별도 파일이 남지 않습니다. 채팅 이력·모델 설정·토큰은 설치 폴더 밖에서 보존합니다. 예전 버전별 설치 폴더는 자동 정리하고 바로가기를 고정 App 경로로 갱신합니다.


오른쪽 패널을 드래그해 조정한 폭을 저장합니다. 창 크기 변경·새로고침·도구 패널 재열기 중 기본 폭으로 되돌리지 않으며, 앱 재실행 후 폭과 선택 탭을 복원합니다. 기존의 700px 상한도 제거했습니다.

내장 브라우저는 마지막 주소를 앱 전체와 채팅별로 저장합니다. **북마크** 버튼으로 추가·해제하고 **북마크 목록 / 방문 기록**에서 검색·열기·삭제할 수 있습니다. 최근 방문 주소는 최대 500개를 보관합니다. **비밀번호 저장 · 자동완성**은 WebView2의 앱 전용 프로필을 사용하며 사이트와 런타임 정책에 따라 저장 확인이 표시됩니다. 비밀번호를 앱 JSON이나 채팅으로 복사하지 않습니다.

**요소 소스 선택**을 누른 뒤 페이지의 원하는 부분을 클릭하면 해당 요소의 HTML이 채팅에 표시됩니다. **선택 소스 첨부**로 AI 입력에 넣고 전송할 수 있습니다. 표시되는 것은 현재 렌더링된 DOM이며 원본 React·서버 소스는 아닙니다. 입력 필드 값은 제외하며, iframe 내부 요소 선택은 지원하지 않습니다.

내장 브라우저의 **전체 캡처 · AI 첨부** 버튼으로 현재 로드된 페이지를 스크롤 아래까지 PNG로 저장하고 AI 입력에 첨부할 수 있습니다. 긴 페이지는 글자가 지나치게 작아지지 않도록 위에서 아래 순서의 이미지로 나눕니다. 전송 버튼을 누르면 선택한 모델에 이미지로 전달됩니다. 원본 PNG는 프로젝트의 `.hermes-captures`에 보관합니다.

AI도 `hermes_browser`의 `screenshot` 동작으로 페이지 전체를 직접 캡처하고 이미지와 원본 경로를 받아 사용할 수 있습니다. `fullPage=false`는 현재 보이는 영역만 캡처합니다. 전체 캡처는 현재 로드된 문서에 대해 한 변 32767px, 합계 64MP까지 지원합니다. 지연 로딩되어 아직 생성되지 않은 내용이나 별도 스크롤 영역 내부의 전체 내용까지 자동 수집한다고 주장하지 않습니다.

이전 버전의 이미지·파일 첨부, 공개 진행 요약, 전체 권한 기본값과 로컬 API 오류 처리 개선을 포함합니다. Windows 릴리스는 태그 소스에서 빌드하고 회귀·공식 엔진 연동·설치 파일 SHA256·공개 페이로드 검사를 통과한 뒤 게시합니다. 실제 회사 서버나 유료 모델은 검증에 사용하지 않았습니다.

설치 완료 후 기본 설치 위치의 소유권 확인된 이전 앱 버전을 자동 제거하고 시작 메뉴 바로가기를 새 버전으로 갱신합니다. 채팅 이력·모델 설정·토큰·브라우저 프로필은 설치 폴더 밖에 보존합니다. 고정 App 폴더의 내용은 재설치 시 모두 교체하고, 예전 버전별 폴더의 별도 사용자 파일은 보존합니다. 실행 중인 이전 버전의 파일이 잠겨 있거나 앱 파일이 수정되어 있으면 해당 경로를 표시하고 정리를 중단합니다.
