# Hermes DevDesk 0.8.6

AI 공개 진행 요약·계획·도구 시작·명령 출력을 채팅에서 기본 펼침으로 표시합니다. 내부 사고 원문은 표시하지 않습니다. 공급자가 진행 요약을 보내지 않는 경우 작업 시작 상태와 도구 실행 기록을 표시합니다.

전체 권한은 기본 활성화되며 프로젝트 밖 파일 접근·명령 실행·네트워크를 승인 질문 없이 실행합니다. 체크를 해제하면 읽기 전용입니다. 기존에 명시적으로 저장한 제한 설정은 보존합니다.

새 프로젝트의 로컬 MCP·브라우저·컴퓨터 도구는 기본 활성화됩니다. 컴퓨터 제어 대상 창 선택과 Windows 운영체제의 권한은 별도로 적용됩니다.

실행: artifacts/release-0.8.6/app/HermesDevDesk.exe

이 버전은 로컬 Windows 빌드입니다. 실제 회사 서버 및 유료 모델은 호출하지 않았습니다.
