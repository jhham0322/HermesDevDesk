# Hermes DevDesk 0.8.4

[Windows 다운로드](https://github.com/jhham0322/HermesDevDesk/releases/tag/v0.8.4)

- 이미지: PNG/JPEG 파일 선택, Ctrl+V 붙여넣기, 드래그 앤 드롭. 외부 이미지는 프로젝트 `.hermes-attachments`로 복사합니다. 파일당 2MB, 최대 4개·합계 3MB. 이미지 지원 모델이 필요합니다.
- 모델: 설정에서 모델명을 입력하고 **입력한 모델 추가**를 누르세요. 같은 서버의 여러 모델을 저장하고 채팅별로 선택합니다.
- 동시 채팅: **새 채팅** 또는 상단 **+**로 여러 탭을 동시에 실행합니다. 초안·첨부·모델·응답·중단·사용량은 채팅별로 분리됩니다. 탭을 닫아도 실행은 계속됩니다.
- 프로젝트: **프로젝트 전체 권한**을 기본으로 켭니다. 프로젝트 쓰기·명령·네트워크는 승인 없이 실행하며 프로젝트 밖 쓰기 경계는 유지합니다. 체크를 끄면 읽기 전용입니다.
- 브라우저: 새 채팅에 기본 연결합니다. 채팅별 페이지에서 탐색·읽기·클릭·입력·JavaScript·프로젝트 파일 업로드를 자동 실행합니다. 사이트 권한을 자동 허용하고 다운로드는 프로젝트 `Downloads`에 저장합니다. OS·장치·서버 권한은 별도입니다.

기존 설정과 이력을 유지합니다. 이전 채팅은 기존 도구 구성을 유지하므로 브라우저 도구는 새 채팅에서 사용하세요.

빌드: .NET 10 SDK와 Windows에서 `scripts/fetch-engine.ps1` 후 `scripts/build.ps1`을 실행합니다. 공식 엔진은 변경하지 않고 동봉합니다. 검증은 VALIDATION.md 참고.
