# 작업 완료 루프 · 0.8.26

입력창의 **완료까지 계속 실행**을 켜고 요청하면 완료 검증 보고까지 자동 계속합니다. 상단 **프로세스**에서 전체 작업 프로세스의 목표·회차·상태를 보고 선택한 프로세스를 종료할 수 있습니다. 승인·외부 입력·연결 복구가 필요하면 상태와 사유를 표시하며 앱 종료 후 자동 재실행하지 않습니다.

**업무·실행 RAG → 오류 목록 / 개선 방법 목록**에서 프로젝트별 오류 횟수·해결 상태·메모와 성공 근거가 연결된 개선 방법을 관리합니다. 같은 오류 두 번부터 RAG 대안을 자동 전달하고 동일 방법의 세 번째 실행을 막습니다. 대안 선택·실행·업무 결과 검증은 선택 모델이 수행합니다. 완료 보고에는 현재 프로세스의 성공 도구 근거를 요구하며, 단순 응답 작업은 전달한 답변을 검증 보고합니다.

# Hermes DevDesk 0.8.23

설치 시 이전 앱·엔진과 설치 파일 점유 프로세스를 강제 종료하고 기존 설치 폴더를 완전히 교체합니다. 읽기 전용·추가·수정 파일도 제거하며, 채팅 이력과 모델 설정은 설치 폴더 밖에서 보존합니다.

일반 채팅의 새 메시지는 매번 새 엔진 세션에서 **현재 메시지와 이번 첨부만** 전달합니다. 이전 대화와 RAG 기록을 자동으로 붙이지 않습니다. 화면의 대화는 보관하며, 진행 중인 요청은 그 요청에서 발생한 도구 호출·결과 문맥을 유지합니다. 과거 방법은 필요한 경우 hermes_memory 검색으로 조회합니다.

현재 목록에 없는 과거 도구 호출·결과는 참고 기록으로 자동 복구하고, 현재 도구에서 가능한 대안을 선택해 사용자 요청을 계속하도록 안내합니다. 기록의 이미지·사용자 지시를 보존하고 완료된 작업을 다시 실행하지 않도록 합니다. 현재 도구를 사용할 수 없는 경우에만 필요한 기능을 구체적으로 설명합니다.

브라우저 위의 **도구 숨기기 / 도구 표시**로 탭·주소·탐색·추가 기능·상태 표시를 한 번에 접고 펼칩니다. 숨김 상태를 저장하며 현재 웹페이지는 그대로 유지합니다.

과거 대화의 도구가 현재 목록에서 빠져도 Anthropic 변환 요청을 계속합니다. 서버가 HTTP 429·503·529로 거절하면 최대 2회 재시도하며, 계속 실패하면 서버 오류 원문을 유지합니다. 성공한 응답의 스트림이나 네트워크 오류는 자동 재전송하지 않습니다.

모델 생성 요청의 10분 제한, Chat 스트림 무응답 2분 제한 및 연결 확인의 15초/60초 제한을 제거했습니다. 사용자가 중단하거나 연결이 종료될 때까지 기다립니다. 대기 중 내부 엔진 스트림은 진행 이벤트로 유지합니다. 외부 서버 오류 상태·본문과 네트워크 오류 문구는 원문을 표시하고, 앱이 만든 오류만 **[HERMES_ERROR]**로 표시합니다(등록된 비밀값은 계속 가립니다).

내장 브라우저에서 **+ 새 탭**으로 최대 10개(전체 채팅 합계)를 열 수 있습니다. 각 탭의 × 또는 **현재 탭 닫기 / 모든 탭 닫기**로 종료합니다. 탭은 채팅별로 구분되며, 북마크·캡처·로컬 HTTP·브라우저 도구 설정은 **브라우저 추가 기능**을 펼쳐 사용합니다.

모델 관리 화면 위쪽의 **새 모델**로 연결을 추가하고, 목록에서 선택한 모델을 수정·삭제할 수 있습니다. 저장 후 및 설정을 다시 열 때 선택 상태를 유지하며, 마지막 모델을 삭제한 뒤에도 새 모델을 추가할 수 있습니다.

로컬 개발 서버는 `localhost:3020`처럼 입력하면 `http://localhost:3020`으로 엽니다. 브라우저의 **로컬 개발 모드 · HTTP / 개발 인증서**는 기본 활성화되며 localhost·127.0.0.1·::1에만 적용됩니다. HTTPS를 지원하지 않는 로컬 개발 포트는 HTTP로 한 번 재접속하고, 자체 서명 개발 인증서를 허용합니다. 모드를 끄면 세션 인증서 허용 캐시도 지웁니다. **로컬 HTTP로 열기**로 같은 포트·경로를 직접 다시 열 수도 있습니다. 외부 도메인·LAN 주소·SSO 계정 접근 권한에는 예외를 적용하지 않습니다.

내장 브라우저 주소창 바로 위에 **← 이전 / 다음 → / 새로고침 / 개발자 도구(F12)**를 표시합니다. 방문 기록에 따라 이전·다음 버튼을 활성화하고, 개발자 도구는 WebView2의 Elements·Console·Network 디버그 창을 엽니다.

**업무·명령·도구 RAG**는 필요한 경우 hermes_memory로 검색합니다. 새 채팅·추가 지시·도구 결과에 과거 기록을 자동 첨부하지 않습니다. 연결된 모델들은 같은 프로젝트의 로컬 지식을 공유하며 별도 사용 명령이 필요하지 않습니다. SQLite DB는 앱 데이터 폴더의 `knowledge/execution-memory.db`에 보관하므로 재설치 후에도 유지됩니다. FTS5/BM25와 한국어 2글자 검색어를 사용하고 외부 임베딩 서버는 필요하지 않습니다.

에이전트 명령은 `hermes_command`로 실행합니다. 같은 채팅에서 같은 방법·오류가 2회 반복되면 다음 동일 실행을 차단하고 원인 확인·다른 접근과 RAG 검색을 안내합니다. 브라우저·컴퓨터·내장 MCP에도 반복 검사와 실행 기록을 적용합니다. 명령은 기존 권한과 공식 sandbox를 유지하며 한 번에 최대 120초입니다.

성공 실행은 자동으로 방법 저장소를 갱신합니다. `hermes_memory`로 검색하고 실제 성공 근거를 인용해 개선 설명을 개정할 수 있습니다. 업무 완료 시 목적·관찰된 실행 절차·실패·산출물 보고를 자동 정리합니다. `workflow.report`는 모델이 작성한 완료 보고이며 업무 목표 검증과 구분합니다. 컴퓨터 제어는 의미 있는 대상·동작을 기록하고 기존 좌표·스냅샷 ID·입력한 문자를 재사용하지 않습니다.

오른쪽 **업무·실행 RAG** 탭에서 방법 검색, 최근 실행 기록, 설명 수정·삭제를 지원합니다. 저장된 내용은 실행 근거를 가진 참고 자료이며 현재 사용자의 지시·권한을 바꾸지 않습니다. 일반 채팅은 새 메시지마다 새 엔진 세션으로 전환하며, 과거 대화 기록은 앱 화면에만 보관합니다.

0.8.9: 긴 대화의 화면을 40개 메시지 단위로 유지하고 이전/다음 기록과 최신 메시지로 이동할 수 있습니다. 메시지 추가 시 기존 화면을 재사용하며, 본문 문단을 하나의 텍스트 컨트롤로 묶고 접힌 도구 결과는 펼칠 때 렌더링합니다. 스트리밍 이력 저장은 2초 간격으로 묶고 완료·종료 시 저장합니다.

연결 설정에서 **새 모델 / 저장 / 선택 모델 삭제**로 모델을 관리합니다. 각 모델은 **모델명, 모델 URL, 토큰**을 독립 저장합니다. 기본은 Chat Completions부터 확인하며 Claude Messages와 Responses도 지원합니다. 전체 API URL을 입력하면 해당 방식을 사용합니다. 인증은 Bearer 토큰입니다. URL은 base URL, `/v1`, 완전한 `/v1/messages` 모두 지원합니다. 고급 설정에서 다른 지원 프로토콜이나 `x-api-key` 인증을 지정할 수 있습니다. 전송 시 선택 모델의 URL·토큰을 적용하고 연결이 바뀌면 엔진을 다시 연결합니다. 실행 중인 요청은 중단 후 모델을 바꿉니다.

**JSON 내보내기 / JSON 가져오기**는 모델별 연결을 옮깁니다. 가져오기는 같은 모델명을 갱신하고 다른 모델은 추가합니다. JSON에는 토큰 원문이 포함됩니다. 앱 내부 저장은 Windows 사용자 DPAPI 보호를 유지합니다. 세 필드만 있는 JSON도 가져올 수 있습니다:

```json
[
  {
    "ModelName": "your-model-name",
    "ModelUrl": "https://your-company.example/v1/messages",
    "Token": "your-token-value"
  }
]
```

로컬 검증은 합성 토큰과 로컬 서버만 사용했습니다. 공식 엔진으로 동일 채팅에서 A → B → A의 서버·모델·인증 전환을 확인했습니다. 5,001개 메시지의 WPF 검사에서 화면 컨트롤은 40개, 추가 렌더링은 약 7ms였습니다(이 PC의 측정값).

0.8.18은 Chat API의 답변 조각을 즉시 전달합니다. 이전 구현은 Chat 요청을 비스트리밍으로 보내고 응답 전체를 기다리다가 4분 제한으로 실패할 수 있었습니다. 서버의 일시적인 지연이나 대기열도 시간 초과 원인이 될 수 있으므로 외부 장애로 단정하지 않습니다. 실행 요청은 `messages`의 텍스트를 문자열로 전달하고 `max_tokens`를 사용하며 불필요한 `parallel_tool_calls`를 보내지 않습니다. 실제 에이전트·도구 호출·후속 답변까지 스트리밍으로 검증합니다.

설치 경로는 항상 `%LOCALAPPDATA%\Programs\HermesDevDesk\App`입니다. 새 설치본을 임시 폴더에서 검증한 뒤 기존 App 폴더를 전체 교체하므로 이전 앱 파일과 별도 파일이 남지 않습니다. 채팅 이력·모델 설정·토큰은 설치 폴더 밖에서 보존합니다. 예전 버전별 설치 폴더는 자동 정리하고 바로가기를 고정 App 경로로 갱신합니다.


오른쪽 패널을 드래그해 조정한 폭을 저장합니다. 창 크기 변경·새로고침·도구 패널 재열기 중 기본 폭으로 되돌리지 않으며, 앱 재실행 후 폭과 선택 탭을 복원합니다. 기존의 700px 상한도 제거했습니다.

내장 브라우저는 마지막 주소를 앱 전체와 채팅별로 저장합니다. **북마크** 버튼으로 추가·해제하고 **북마크 목록 / 방문 기록**에서 검색·열기·삭제할 수 있습니다. 최근 방문 주소는 최대 500개를 보관합니다. **비밀번호 저장 · 자동완성**은 WebView2의 앱 전용 프로필을 사용하며 사이트와 런타임 정책에 따라 저장 확인이 표시됩니다. 비밀번호를 앱 JSON이나 채팅으로 복사하지 않습니다.

**요소 소스 선택**을 누른 뒤 페이지의 원하는 부분을 클릭하면 해당 요소의 HTML이 채팅에 표시됩니다. **선택 소스 첨부**로 AI 입력에 넣고 전송할 수 있습니다. 표시되는 것은 현재 렌더링된 DOM이며 원본 React·서버 소스는 아닙니다. 입력 필드 값은 제외하며, iframe 내부 요소 선택은 지원하지 않습니다.

내장 브라우저의 **전체 캡처 · AI 첨부** 버튼으로 현재 로드된 페이지를 스크롤 아래까지 PNG로 저장하고 AI 입력에 첨부할 수 있습니다. 긴 페이지는 글자가 지나치게 작아지지 않도록 위에서 아래 순서의 이미지로 나눕니다. 전송 버튼을 누르면 선택한 모델에 이미지로 전달됩니다. 원본 PNG는 프로젝트의 `.hermes-captures`에 보관합니다.

AI도 `hermes_browser`의 `screenshot` 동작으로 페이지 전체를 직접 캡처하고 이미지와 원본 경로를 받아 사용할 수 있습니다. `fullPage=false`는 현재 보이는 영역만 캡처합니다. 전체 캡처는 현재 로드된 문서에 대해 한 변 32767px, 합계 64MP까지 지원합니다. 지연 로딩되어 아직 생성되지 않은 내용이나 별도 스크롤 영역 내부의 전체 내용까지 자동 수집한다고 주장하지 않습니다.

이전 버전의 이미지·파일 첨부, 공개 진행 요약, 전체 권한 기본값과 로컬 API 오류 처리 개선을 포함합니다. Windows 릴리스는 태그 소스에서 빌드하고 회귀·공식 엔진 연동·설치 파일 SHA256·공개 페이로드 검사를 통과한 뒤 게시합니다. 실제 회사 서버나 유료 모델은 검증에 사용하지 않았습니다.

설치 완료 후 기본 설치 위치의 소유권 확인된 이전 앱 버전을 자동 제거하고 시작 메뉴 바로가기를 새 버전으로 갱신합니다. 채팅 이력·모델 설정·토큰·브라우저 프로필은 설치 폴더 밖에 보존합니다. 고정 App 폴더의 내용은 재설치 시 모두 교체하고, 소유권이 확인된 예전 버전별 설치 폴더는 추가 파일까지 전체 제거합니다. 실행 중인 이전 앱과 설치 파일 점유 프로세스를 종료하고 읽기 전용·수정된 앱 파일도 교체합니다.
