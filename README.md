# Hermes DevDesk 0.8.5

[Windows 다운로드](https://github.com/jhham0322/HermesDevDesk/releases/tag/v0.8.5)

- 이미지: PNG/JPEG 파일 선택, Ctrl+V 붙여넣기, 드래그 앤 드롭. 외부 이미지는 프로젝트 `.hermes-attachments`로 복사합니다. 파일당 2MB, 최대 4개·합계 3MB. 이미지 지원 모델이 필요합니다.
- 모델: 설정에서 모델명을 입력하고 **입력한 모델 추가**를 누르세요. 같은 서버의 여러 모델을 저장하고 채팅별로 선택합니다.
- 동시 채팅: **새 채팅** 또는 상단 **+**로 여러 탭을 동시에 실행합니다. 초안·첨부·모델·응답·중단·사용량은 채팅별로 분리됩니다. 탭을 닫아도 실행은 계속됩니다.
- 프로젝트: **프로젝트 전체 권한**을 기본으로 켭니다. 프로젝트 쓰기·명령·네트워크는 승인 없이 실행하며 프로젝트 밖 쓰기 경계는 유지합니다. 체크를 끄면 읽기 전용입니다.
- 브라우저: 새 채팅에 기본 연결합니다. 채팅별 페이지에서 탐색·읽기·클릭·입력·JavaScript·프로젝트 파일 업로드를 자동 실행합니다. 사이트 권한을 자동 허용하고 다운로드는 프로젝트 `Downloads`에 저장합니다. OS·장치·서버 권한은 별도입니다.

기존 설정과 이력을 유지합니다. 이전 채팅은 같은 대화에서 계속 작업할 수 있으며 프로젝트 권한은 현재 선택을 적용합니다. 설정·모델 변경 뒤에도 다시 연결해 이어서 사용합니다. 이미 시작한 대화의 도구 목록은 유지합니다.

- 채팅 삭제: 채팅 우클릭 또는 상단 채팅 메뉴 → **채팅 삭제**. 앱 대화 기록과 초안을 삭제하며 프로젝트 파일·Git 이력·사용량은 유지합니다. 실행 중인 삭제 대상 채팅은 먼저 중단하세요.
- 로컬 커밋: 채팅 상단 **Git 커밋** → 파일 선택 → 메시지 입력 → **선택한 파일 로컬 커밋**. 저장소가 없으면 이 창에서 생성할 수 있습니다. 작성자 설정은 프로젝트에만 저장합니다. 선택하지 않은 스테이징은 유지하고 원격 Push는 별도입니다.
- 아이콘: 금색 날개와 H 모티프의 전용 아이콘을 앱·작업표시줄·설치 파일에 적용했습니다.

빌드: .NET 10 SDK와 Windows에서 `scripts/fetch-engine.ps1` 후 `scripts/build.ps1`을 실행합니다. 공식 엔진은 변경하지 않고 동봉합니다. 검증은 VALIDATION.md 참고.

- 오류 로그: 이미지 첨부·드래그·붙여넣기와 예기치 않은 앱 오류를 프로필 `logs`에 기록합니다. **도움말 → 오류 로그 폴더 열기**로 확인합니다. 손상 파일과 너무 큰 클립보드 이미지는 첨부하지 않고 안내합니다.
- 창 복원: 크기·위치·최대화 상태를 자동 저장합니다. 다음 실행에서 복원하며 모니터가 사라졌으면 현재 화면 안으로 보정합니다.

로컬 Git 커밋에는 PC의 Git이 필요하며 파일 메뉴의 로컬 Git 설정에서 git.exe 경로를 지정할 수 있습니다.
